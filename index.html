Relatório e fundamentação de projeto para apresentação de avaliação

1. Justificação das Escolhas Técnicas

Modelo de IA (Google Gemini 3 Flash Preview)

Escolhido por ser um modelo gratuito de alta velocidade, com suporte nativo para língua portuguesa e excelente capacidade de seguir instruções rígidas (*System Prompt Instruction*).

Mecanismo RAG Grounded (Retrieval-Augmented Generation)

A informação do site oficial da ETPC foi recolhida e estruturada numa Base de Conhecimento local/Supabase. A cada pergunta, o contexto exato e o URL de origem são injetados no prompt da IA, impedindo a invenção de dados (alucinação).

Estratégia de Fallback & Tolerância a Falhas

Caso a API do Gemini atinja limites de cota ou perca ligação de rede, a aplicação aciona automaticamente um algoritmo de pesquisa semântica/chave na base de dados ETPC local, garantindo que o utilizador nunca fica sem resposta.

Arquitetura de Front-End & Hospedagem

Desenvolvida com HTML5, Tailwind CSS e JavaScript ES6 moderno num único ficheiro de alto desempenho, ideal para ser alojado no Vercel ou Netlify sem necessidade de servidor complexo.

3. Principais Dificuldades Encontradas & Soluções

  • Dificuldade: Impedir que o modelo de IA respondesse a perguntas gerais de conhecimentos gerais (ex: receitas ou futebol).
    ↳ Solução: Implementação de um System Prompt rígido com regras de recusa expressa e delimitação do contexto.
  • Dificuldade: Evitar alucinações sobre dados não existentes no site da ETPC.
    ↳ Solução: Filtro de Grounding em tempo real com injeção obrigatória de fontes oficiais.
  • Dificuldade: Manter a aplicação funcional mesmo quando sem internet ou sem cota na API do Gemini.
    ↳ Solução: Criação de um motor de pesquisa interna por correspondência semântica e palavras-chave.
